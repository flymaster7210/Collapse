twine

Use code with caution.

🛠️ Syntax Breakdown

When writing multi-conditional (if:) statements, keep these fundamental Harlowe rules in mind:
1. Do not use the is keyword right after and: You must fully state each comparison explicitly. For example, (if: $score > 5 and is < 10) is invalid. You must re-state the variable: (if: $score > 5 and $score < 10). [1] (https://twinery.org/archive/forum/discussion/8609/harlowe-multiple-conditions-in-an-if-macro.html)
2. Boolean Shortcuts: If you are checking if a boolean variable is true, you don't actually need to type is true. Simply naming the variable evaluates it. [1] (https://twinery.org/cookbook/conditionalstatements/harlowe/harlowe_conditionalstatements.html)

📘 Common Use Cases


1. Checking Multiple Booleans (Short Syntax)

If you need to ensure the player has completed multiple tasks, just separate the variables with and: [1] (https://twinery.org/archive/questions/10408/how-to-add-multiple-conditions-in-one-if-macro.html)
twine
(if: $hasSword and $hasShield)[
    You are fully equipped for battle!
]
Use Code with Caution.

2. Checking Ranges (Numbers)

To check if a value falls between a specific range, explicitly write out both sides: [1] (https://twinery.org/archive/forum/discussion/8609/harlowe-multiple-conditions-in-an-if-macro.html)
twine
(if: $health > 20 and $health < 80)[
    Your health is stable, but not perfect.
]
Use code with caution.

3. Combining and with else-if and else

You can chain these conditions into larger logic structures using (else-if:) and (else:) macros: [1] (https://www.youtube.com/watch?v=3EM7Zuw84xU&t=223), [2] (https://www.youtube.com/watch?v=qw5ESb0QXUY)
twine
(if: $hasKey is true and $gold >= 10)[
    You unlock the door and bribe the guard.
]
(else-if: $hasKey is true and $gold < 10)[
    You have the key, but you don't have enough gold to appease the guard.
]
(else:)[
    You don't even have the key. The guard ignores you.
]
Use code with caution.
